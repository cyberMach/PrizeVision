## Brand & Style
The design system establishes a high-trust, premium lottery companion experience bridging fintech-grade precision with the celebratory excitement of high-stakes gaming. Moving decisively away from outdated felt-green gaming tropes, it anchors on deep nocturnal slate blues and luminous Celtic Blue, engineered to evoke confidence, transparency, and prestige.

The aesthetic fuses **Modern FinTech Glassmorphism** with **Tactile Precision Gaming**:
- **Atmosphere:** Deep midnight surfaces layered with optical clarity, crisp translucent panels, and focused luminous glows.
- **Tone:** Methodical, secure, yet electrifying upon victory.
- **Target Audience:** Modern lottery players and syndicate managers who demand instantaneous ticket scanning, exact odds analysis, automated jackpot tracking, and an elevated VIP visual standard.

## Colors
The palette balances deep spatial stability with striking chromatic hierarchy, ensuring that critical jackpot metrics and scan states command immediate focus.

- **Primary (`#3971B8` / `#2563EB`):** Celtic Blue serves as the core interactive engine—driving primary actions, focus indicators, active navigation tabs, and system confidence.
- **Secondary (`#F6E6A5` / `#F59E0B`):** Warm Vanilla Gold reserved strictly for wins, matched numbers, multiplier badges, jackpot milestones, and celebration moments.
- **Tertiary (`#38BDF8` / `#C8D69B`):** Luminous Sky and subtle Tea Green for data visualizations, ticket scan target reticles, odds delta indicators, and secondary tags.
- **Neutral Surface Foundation:**
  - `Base Canvas`: `#0F172A` (Deep Midnight Blue)
  - `Layer 1 Surface`: `#132238` (Midnight Slate)
  - `Layer 2 Card/Sheet`: `#1A2E4C` (Raised Celtic Slate)
  - `Layer 3 Elevated/Modal`: `#223B61` (Illuminated Blue-Grey)
- **Text & Foreground Hierarchy:**
  - High Emphasis: `#FFFFFF` (Jackpot values, key metrics, headers)
  - Medium Emphasis: `#F8FAFC` (Ivory primary copy, labels)
  - Low Emphasis: `#94A3B8` (Timestamps, non-active odds, helper captions)

## Typography
The typography system balances futuristic poise with operational clarity.

- **Headlines (Sora):** Selected for its geometric geometry and distinct modern curve profile. Sora delivers commanding impact for jackpot numbers and screen titles without appearing informal.
- **Body & Interactive (Hanken Grotesk):** Provides frictionless readability in low-light environments, neutral contrast, and crisp kerning across dense ticket line items.
- **Numbers & Counters (JetBrains Mono):** Reserved for lottery ball digits, serial codes, ticket validation strings, and countdown clocks to guarantee tabular consistency and zero optical jitter during countdowns.

## Layout & Spacing
A fluid column system optimized for one-handed mobile navigation with safe-area hardware insets:

- **Mobile Viewports (<600px):** 4-column fluid layout with `margin: 1rem` and `gutter: 1rem`. Component density remains high to ensure ticket matrices and multi-draw views fit cleanly without excessive vertical pagination.
- **Tablet / Large Mobile (600px - 1024px):** 8-column layout with `margin: 2rem` and `gutter: 1.5rem`. Split views support the ticket scanner camera feed on the left pane and real-time scanned ticket outputs on the right.
- **Vertical Rhythm:** Strict adherence to an 8px base grid (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 40px). Interactive touch targets must maintain a minimum bounding height of 48px.

## Elevation & Depth
Depth is produced through translucent dark-surface layering combined with atmospheric lighting:

- **Layer 0 (Base Canvas):** Solid `#0F172A`.
- **Layer 1 (Recessed Container):** Solid `#132238` with an inset `0 1px 2px rgba(0, 0, 0, 0.4)` for input fields, unselected draw cards, and inactive ball slots.
- **Layer 2 (Primary Floating Panels):** Semi-opaque `#1A2E4C` at 85% opacity with `backdrop-filter: blur(16px)` and a hairline border of `1px solid rgba(255, 255, 255, 0.08)`.
- **Layer 3 (Modals & Victory Sheets):** Solid `#223B61` supported by ambient drop shadows: `0 20px 40px -15px rgba(0, 0, 0, 0.65)`, complemented by a top highlight rim of `1px solid rgba(246, 230, 165, 0.25)` when winning states are present.
- **Winning Highlights & Glows:** Selected or winning balls utilize a radial bloom: `box-shadow: 0 0 16px rgba(246, 230, 165, 0.35)`. Active scanning reticles use Celtic Blue bloom: `box-shadow: 0 0 20px rgba(57, 113, 184, 0.4)`.

## Shapes
The UI applies an intentional curved architectural language (`roundedness: 2`):

- **Standard Cards & Modals:** `rounded-lg` (16px / 1rem) to soften technical data and create comfortable framing for ticket grids.
- **Inputs & Secondary Buttons:** `rounded` (8px / 0.5rem) to preserve structured alignment.
- **Interactive Badges, Pills & Lottery Balls:** Fully circular (`rounded-full` / 9999px) to mirror traditional spherical lottery balls, status badges, and quick-add actions.

## Components

### Lottery Balls (Numbers & Powerballs)
- **Standard Draw Ball:** 40x40px circular container in `#132238` with a subtle `1px solid rgba(255, 255, 255, 0.12)`. Number displayed in JetBrains Mono (`label-numeric-md`), centered, `#F8FAFC`.
- **Matched / Winning Ball:** Circular container with a gradient fill from `#F6E6A5` to `#F59E0B`. Number displayed in `#0F172A` with weight 700. Features an ambient glow of `0 0 12px rgba(246, 230, 165, 0.4)`.
- **Special / Multiplier Ball:** Circular container in `#2563EB` with `#FFFFFF` text and a subtle `#38BDF8` ring outline.

### Buttons
- **Primary Action (Scan Ticket / Play):** Fill using Celtic Blue gradient (`#3971B8` to `#2563EB`), height 52px, `rounded-lg`, text in `#FFFFFF` Sora 16px bold. Subtle inner highlight along the top border `1px solid rgba(255, 255, 255, 0.2)`.
- **Secondary (Odds / Details):** Semi-transparent `#1A2E4C` surface with `1px solid rgba(57, 113, 184, 0.4)`, text in `#F8FAFC`. Active state transitions border to `#38BDF8`.
- **Destructive / Clear:** Inset `#132238` with `#94A3B8` copy, shifting to `#EF4444` on pressed state.

### Cards & Ticket Slips
- **Ticket Container:** Layer 2 background (`#1A2E4C`) with a micro-perforated decorative separator line dividing draw metadata from the number grid. Rimmed with a hairline `1px solid rgba(255, 255, 255, 0.08)`.
- **Jackpot Banner Card:** Deep gradient from `#132238` transitioning diagonally to `#1A2E4C` with a warm gold top accent border (`#F6E6A5`, 2px thick). Contains the running prize pool in `headline-xl` Sora and real-time countdown timer in JetBrains Mono.

### Inputs & Ticket Scanner Reticle
- **Text / Code Input:** 48px height, recessed background `#132238`, text in `#FFFFFF`, placeholder `#64748B`. Border `1px solid rgba(255, 255, 255, 0.1)`. Focus state applies a border of `#3971B8` and a `0 0 0 2px rgba(57, 113, 184, 0.25)` ring.
- **Scanner Viewfinder Overlay:** Translucent backdrop with a clear central bounding box defined by 4 corner brackets in `#38BDF8`. A vertical animated Celtic Blue scanning bar travels continuously with soft vertical blur.

### Chips & Filter Pills
- **Draw Filter Pills:** Height 34px, fully pill-shaped (`rounded-full`). Unselected state uses `#132238` with `#94A3B8` text. Selected state uses solid `#3971B8` with `#FFFFFF` text and a soft blue shadow.

### Checkboxes & Segmented Controls
- **Checkboxes:** 22x22px square with `rounded` (4px). Background `#132238`, border `1.5px solid #3971B8`. When checked, solid `#3971B8` fill with an ivory `#FFFFFF` checkmark icon.
- **Segmented Range Control:** Background `#0F172A` capsule housing sliding indicator pill `#223B61`, switching seamlessly between game modes (e.g., Daily, Powerball, Mega Draws).
